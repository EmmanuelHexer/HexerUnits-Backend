# Hexer Units – Backend

This is the backend of a **Unit Converter** web application, built with **ASP.NET Core**. It exposes RESTful API endpoints that handle various unit conversion operations (e.g., temperature, length, weight) and returns the results to the frontend upon request.

The backend was developed using **C#** and follows clean architectural principles. It uses **classes** to encapsulate conversion logic, and the project structure separates concerns through the use of **controllers**, **services**, and **models**, making the codebase more maintainable and testable.

Additionally, the API includes **input validation**, **error handling**, and is designed to be easily extensible for supporting additional unit types in the future.

✅ **Unit tests** have been written to ensure the reliability and correctness of the conversion logic and API endpoints.
